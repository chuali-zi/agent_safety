**真人录音的连带要求**（DEC-5）

- 先按新镜头表写离屏旁白稿，**逐段试读掐表**——真人语速比预估慢，9:30 的稿子常读成 10:30；
- 每段录音与画面分开录、后期对齐，比一边操作一边讲更容易一条过；
- 统一麦克风与房间，避免分段之间音色跳变；录前后各留 2 秒静音便于剪辑；
- 旁白稿定稿后再更新 `D3-video-subtitles.srt`（现有 SRT 对应旧镜头顺序，需重写）。

**其余制作要点**

- **clean/tampered 验签对照那 30 秒必须留**——一个 exit 0 一个 exit 1，是"审计溯源完整性"最省解释的画面。
- 屏幕上每个数字必须等于 `FROZEN-NUMBERS.md`。**先冻数字（8/9）再录。**
- 分 10–12 个 ≤90 秒短片段录，每段一个概念；**先做一次完整的不录制预演**专门找 UI 崩点。
- 终端里露一次 `git rev-parse HEAD` 且与 D1 PDF 上的 commit 一致——成本近零，可信度加成大。
- 现行脚本 §2 环境准备、§4 失败恢复、§5 合成与验收三节**保持有效**，直接复用。
