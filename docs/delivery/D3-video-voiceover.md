## 逐镜正文

### 1. 冷开场（0:00–0:40）

这里是 XA-Guard，赛题编号 XA-202620。它把输入与数据安全、执行安全、供应链安全和审计合规
接到同一个运行时闭环。接下来不先讲架构，而是先看同一条攻击是否造成了不同的真实业务后果。

### 2. live A/B（0:40–2:10）

这是已经执行并封存的邮箱间接提示注入 live A/B。两侧读取同一封合成邮件。
恶意指令试图把合成市民数据 `cit-1001` 外发到信任边界之外。

Null 侧直接 `allow`：外发次数一、数据暴露为真，并命中 `sensitive-egress`。
接入 XA-Guard 后，同一输入在外部发送前被 `deny`，外发次数为零，数据暴露为假。

冻结十轮中，Null 十次全部泄漏；XA-Guard 泄漏零次，protected 基础设施错误为零。
十次受保护 replay 全部通过。这是合成确定性场景，不外推为通用攻击率。

### 3. Gate1 识别量化（2:10–2:50）

Gate1 六个输入攻击族共六十例，全部识别阻断。五十八个放行负控制误报为零，
Wilson 95% 上界 6.21%，规则层 p95 0.04 毫秒。结果来自规则检测器；
`independent_holdout=false`，切分仅作诊断；时延不含模型与完整链路。

### 4. 高风险命令（2:50–3:40）

执行安全看业务后果，而不只看分类标签。Null 路径产生一次下游调用。
未批准路径先 `require_approval`，随后 `deny`，下游调用保持为零。
独立审批后进入 `allow`，下游调用为一。系统能拦住未授权动作，也允许合规动作通过。

### 5. AIBOM（3:40–4:20）

AIBOM 检查源码、依赖、能力声明和 provenance。恶意 snippet 命中网关后 `deny`、下游为零；
干净 artifact 批准后 `allow`、下游为一。A、B 放行，C 人工复核，D、F 拒绝；
画面不虚构未记录的具体等级。

### 6. 身份与动态委托（4:20–5:10）

Alice 通过 Keycloak PKCE 登录，BFF 再做 token exchange。页面展示数据库中的实时委托链。
浏览器自报身份不被信任。伪造签名、错误 audience、伪造主体均在执行前失败关闭。
assignment 撤权后的访问同样被拒绝；下游创建增量和 Effect 增量都为零。

### 7. 真实副作用与 Effect（5:10–6:00）

Alice 委托 Agent 创建演示工单。XA-Guard 在触达业务 API 前先登记 `PREPARED` intent。
系统以 `effect_id` 作为下游幂等键执行写操作，成功后状态进入 `AVAILABLE`。
恢复所需的身份、参数、幂等键和补偿合同在副作用发生前已经存在。

### 8. 职责分离 Undo（6:00–7:10）

Alice 可以申请撤销，但不能批准自己的请求，页面明确显示 `NO APPROVER ROLE`。
Dora 通过独立 Keycloak 会话审批；系统确认她与申请人不是同一 subject。
独立 Worker 读取加密恢复合同，以内部签名授权调用取消工单。
Effect 从 `AVAILABLE` 进入 `COMPENSATED`，工单从 open 变为 cancelled。
语义是至少一次调度加下游幂等，不宣称绝对 exactly-once。

### 9. 双链证据（7:10–8:10）

原动作、审批和补偿进入 Gate6 与 Effect 两条哈希链，
再由 Effect、业务引用和两个 trace 交叉关联。
clean 审计副本独立校验，退出码为零；篡改一条记录后，tampered 副本退出码为一。
原始 audit hash 保持不变。一个通过、一个失败，让篡改检出可以离线复核。

### 10. 工程与部署（8:10–9:00）

Reference Compose 的六个服务全部健康，最终候选通过十一项全故障场景。
本地三节点 kind 的安装、升级、迁移重跑、接管、网络策略和回滚全阶段通过。
三轮 incremental p95 为 45.109、42.141、43.934 毫秒，
单侧 95% bootstrap 上界均小于 50 毫秒。

### 11. 边界与收束（9:00–9:30）

攻击证明限合成场景；MCP target 只记录脱敏调用；kind 只证明本地三节点，生产仍需组织验收。
XA-Guard，XA-202620：前有身份，途中六关，后有撤销，全程有证据。
